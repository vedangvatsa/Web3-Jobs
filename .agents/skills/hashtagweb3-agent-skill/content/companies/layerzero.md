LayerZero is an interoperability protocol enabling cross-chain messaging between 70+ blockchains. It powers omnichain applications including bridges, DEXs, and lending protocols.

## Products and Services

- **LayerZero Protocol**: Cross-chain messaging layer
- **OFT Standard**: Omnichain Fungible Token standard
- **ONFT Standard**: Omnichain Non-Fungible Token standard
- **LayerZero Scan**: Cross-chain transaction explorer
