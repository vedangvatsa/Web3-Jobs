# Hashtag Web3 MCP Server Card

Model Context Protocol server definition for Hashtag Web3 documentation queries.

- Server name: hashtagweb3-docs
- Transport: streamable-http
- Endpoint: https://hashtagweb3.com/mcp

## Capabilities

- Query the 200+ term blockchain glossary
- Retrieve career guides and developer documentation
- Answer questions about the Hashtag Web3 public API surface

## Raw Card

The canonical JSON server card is served at `/.well-known/mcp-docs/server-card.json` with Content-Type `application/json`.
