# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Event content

Fetched event records, descriptions, and editorial guides are organized under [`content/events/`](content/events/README.md). Use the [event index](content/events/INDEX.md) to find a record and its source, and see the [Google Event schema audit](content/events/SCHEMA.md) for structured-data coverage.
