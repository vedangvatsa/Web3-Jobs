# Hashtag Web3 Agent Skill

This skill allows agents to interface with Hashtag Web3 to:
- Retrieve and search live Web3 & blockchain job listings.
- Fetch real-time crypto news headlines and articles.
- List global Web3 events, hackathons, and summits.
- Look up blockchain definitions and glossary terms.

## Tool Integrations
- `search_jobs`
- `search_glossary`
- `get_news`
- `get_events`
