# Event description editing

- Include only useful, verified facts from organizer or primary event sources.
- Short, direct paragraphs are sufficient. Headings are optional, not a template requirement.
- Use a heading only when the section contains distinct, substantive information.
- Remove empty sponsor labels, navigation text, slogans, generic networking promises, and sections that add no new information.
- Never pad descriptions to meet a word count. Prefer a shorter factual description to headings followed by filler.
- Preserve source provenance and distinguish announced plans from confirmed outcomes.
