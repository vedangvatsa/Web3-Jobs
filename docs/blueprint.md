# **App Name**: Web3 Job Board Aggregator

## Core Features:

- RSS Feed Aggregation: Fetch job postings from the following RSS feeds: https://politepol.com/fd/JEeZwG4KK7uT.xml, https://politepol.com/fd/HI6pMDlyEO7j.xml, https://politepol.com/fd/sDzglCq7RCpG.xml, https://politepol.com/fd/bs9i34afSjHS.xml.
- Duplicate Check: Check for duplicate job postings to prevent redundancy. 
- Scheduled Updates: Schedule automatic feed checks every 6 hours for updates. 
- Job Listing Display: Display job postings in a clear and organized list format with title and company. 
- Filtering and Sorting: Filter and sort job postings by different criteria such as job title, and company. 
- Search Functionality: Provide a search bar to allow users to search for specific job titles, companies, or keywords. 

## Style Guidelines:

- Primary color: Vibrant blue (#29ABE2) to convey trust and innovation in the Web3 space.
- Background color: Light gray (#F5F5F5) for a clean and modern look.
- Accent color: Electric purple (#7354F3) to highlight important elements like filters and call-to-action buttons, suggesting forward-thinking.
- Font pairing: 'Inter' (sans-serif) for both headings and body text, for a clean and readable interface. 
- Use simple, geometric icons to represent different job categories or filter options. 
- Use a grid-based layout to display job listings, ensuring a visually appealing and organized presentation. 
- Subtle animations or transitions when loading new job postings or filtering results.
