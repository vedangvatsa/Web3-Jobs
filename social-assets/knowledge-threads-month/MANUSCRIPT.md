## 2026-10-26 | N03 | Five Solidity interview questions with short answers

1. A view function can still cost gas, and a packed struct can still cost more to update.
Five Solidity interview questions from our bank, with short answers for the EVM and Solidity 0.8.x.

2. Q: How do storage, memory and calldata differ?
A: storage persists between calls. memory is writable scratch space for a call. calldata is read-only argument data. Use calldata for reference-type inputs you do not need to modify.

3. Q: What is a modifier? Give an example.
A: Reusable logic around a function body. onlyOwner can run require(msg.sender == owner) before _;. The _; placeholder runs the body; code after it runs afterward.

4. Q: What are view and pure for?
A: view may read state but cannot modify it. pure may neither read nor modify state. An off-chain eth_call pays no network fee; execution inside a transaction still consumes gas.

5. Q: How does delegatecall enable an upgradeable proxy?
A: Implementation code uses the proxy's storage and address, preserving msg.sender and msg.value. Upgrades change the implementation pointer; storage layout must stay compatible.

6. Q: How should you order struct fields for storage packing?
A: Group fields that fit in 32 bytes. uint128, uint128, uint256 uses 2 slots; uint128, uint256, uint128 uses 3. Fewer slots do not guarantee cheaper writes.

## 2026-10-29 | N04 | Five frontend dApp interview questions with short answers

1. Displaying 1000000 as a token balance can be a million-fold mistake. For a 6-decimal token, that is 1 token.
Five frontend dApp interview questions on reads, units, pending transactions, NFTs and signing, with short answers.

2. Q: What does a provider do in ethers or viem?
A: In ethers v6, a Provider reads chain data; a Signer authorizes transactions. In viem, Public Client exposes reads and Wallet Client handles signing via a wallet or local account.

3. Q: How do you display a uint256 token balance?
A: Use formatUnits(balance, decimals), keeping balance as bigint. In viem, formatUnits(1000000n, 6) returns '1'. Get decimals for that token and chain; never assume 18.

4. Q: Why is an Ethereum transaction stuck, and what should the UI do?
A: Low fees or an earlier pending nonce can block it. Show pending status. A speed-up uses the same nonce with higher fees; cancellation is a competing replacement, not a guarantee.

5. Q: How do you show a wallet's NFTs across contracts?
A: Query an ownership indexer by wallet and chain, paginate results, then render token IDs, metadata and images. Handle missing media. A balanceOf call cannot list every collection.

6. Q: Why use EIP-712 rather than personal_sign for orders?
A: It signs typed fields with a domain, so wallets can show structured terms. Include chainId and verifyingContract. The app must still enforce nonces and expiry.

## 2026-11-05 | C07 | Five smart-contract security questions with concrete answers

1. A valid signature can be reused, and a token can transfer less than the amount requested.
Five smart-contract security interview questions with answers about tools, accounting, replay, fuzzing and read-call limits.

2. Q: What is Slither, and what can it find?
A: A static analyzer for Solidity and Vyper. It flags patterns such as reentrancy, tx.origin authorization and unchecked calls. Findings need triage; a clean run does not prove safety.

3. Q: What token behavior do you check first in a staking audit?
A: Transfer fees and rebases. For a supported fee-on-transfer token, credit the received balance delta, not the requested amount. Rebases need separate accounting or explicit rejection.

4. Q: What is signature replay, and how do you stop it?
A: Reusing a valid signed action. Sign and consume a nonce, bind the domain to chainId and verifyingContract, and enforce a deadline. EIP-712 alone does not prevent reuse.

5. Q: What is fuzzing, and which tool supports it?
A: Generated inputs search for broken properties. Echidna can fuzz call sequences; Foundry supports fuzz and invariant tests. Example for a simple custody vault: assets must cover recorded liabilities.

6. Q: Can an unbounded view loop cause denial of service?
A: Yes. eth_call still executes on an RPC node and can hit gas caps or timeouts. A getAllOwners() that grows forever can fail. Return bounded pages instead.
